# 游戏音效接入（2026-11-26）

用户授权：用已下载的音效包给本地游戏添加音效。本轮在既有集成分支完成；不提交、不推送、不改远程仓库。保留用户封面PSD和原始设计资料。

## 已接入内容

- 从四个Kenney包和Cozy Cafe中选取33个原始音频副本，运行库登记37个音效事件；完整下载包仍保存在工程外outputs/zhenweiyan-audio-20261126。
- 界面：按钮悬停／点击、弹窗打开／关闭、失败反馈、保存及采购确认；沿用现有总音量设置。
- 料理：M1短落刀、M2点火操作提示、M3轻金属翻炒反馈、M6调味起手、M7装盘及miss提示。替换原合成反馈，不与旧音双播；隐藏厨房立即停掉残留反馈。既有140BPM、完整casual原曲、评分窗口和时钟保持。
- 经营：新订单以实际落座点单为准，成品出餐口／取盘／桌边送达分开提示，现金／小费仅由真实记账触发。试吃不播收银。主店隐藏、外镇后台不播可见经营动作；分店只在当前可见内部播。
- 世界：三种中性脚步按碰撞后位移及原步距轮换；静止、受阻、禁止操作时不播，不假称匹配了实际地表材质。
- 剧情：原生VN读取当前发言角色的真实表情ID，疑惑／高兴／得意／困扰／生气使用非人声短提示；同角色同表情不逐行重复。通常／哭哭／无语保留留白，不伪造人声。普通对白仅短tick；auto／skip不发提示。
- UI／世界各6声部，有界复用，同事件限流；暂停拒收世界事件并冻结现有世界音，暂停菜单按钮可用。换场景／切槽／返回标题／退出清理旧音，旧Shop信号在释放前断开。

## 边界与授权

未实现或假结算战斗，未在deferred接口播胜利／奖励声；没有把缺失的火焰、人声、冒泡等编造为现有素材。未增加菜谱、动作、金钱、库存、评分、存档schema或Autoload。

使用../work/godot-gdscript-patterns-SKILL.md；GRILL_SKILL=NOT_AVAILABLE，依据DEVELOPMENT_PROTOCOL进行等价审查，GRILL_RESULT=NO_BLOCKING_PRODUCT_QUESTIONS。可调选材／音量／限流记AI-093-SFX。

Kenney原始授权和Cozy自定义授权均位于assets/audio/sfx/licenses；build旁也提供audio-licenses与AUDIO_LICENSES.md。Cozy可随商业游戏使用，不得作为独立音效库再分发。网页署名Spaceyyy与包内Bramble & Byte差异均保留。

## 实现入口

src/platform/sound_effects.gd由Shell持有，静态request仅沿当前节点祖先找本实例；不建立全局存活对象。Shop.sound_requested为呈现信号，钱物仍由原Shop唯一负责。TDBeatAudio只替换play_feedback，不改音乐prepare/follow_chart。VN只消费原runner状态，不创建第二推进器。

精确导出清单显式列出33个音频；仅列GDScript不够。导出工具逐项检查SFX.import和原始授权存在，避免出现编辑器能播、发行包缺失的情况。

## 试听建议

1. 从固定EXE打开设置，确认总音量合适；点击按钮、打开／关闭面板。
2. 在地图上走动再停下，确认脚步只随移动出现。
3. 开始切配与料理，比较落刀、翻炒、调味和miss反馈，暂停／退出厨房应停声。
4. 经营时区分出餐口、取盘、送桌和收银提示；剧情试吃不应出现收银。
5. 正常推进剧情查看疑惑等表情，再使用快进核对静音。

此处为建议人工验收步骤，不表示已经由人听过。整体混音和主观听感仍待用户试玩。
