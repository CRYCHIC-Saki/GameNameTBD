## 番茄炒蛋：没有工序菜单

1. WASD/方向键走到左上番茄箱，E拿取；右上砧板E放下，切菜自动开始。
2. 当前番茄切块谱固定为“空格落刀→D右转→空格落刀”，看各音符的收缩环依次操作。转向也必须按拍，全中得到块；不需要故意漏刀。自动回厨房后砧板E取走，灶台E放入，再放一份鸡蛋。
3. 空手在灶台E：自动点火→下油/下料→翻炒并控温→材料柜调味→勾芡→出锅。每段结束自动继续，失误会降分；不需要也不能选下一工序。
4. 出锅界面先预告2秒，提示“现在按住空格”后，在2秒起手宽限内按住；实际持满约2秒到绿区中心松开。按住后才开始蓄力，不会因为看提示晚了半秒而提前截断。回厨房端盘到出餐台E提交。
5. 看两位客人的评价，E返回再拿料。提高谱面命中和火候表现；切型由菜谱规定，不自由选刀数或转向。本轮没有份量输入、拖盘或回锅按钮。

## 七个模块

| 模块 | 输入与观察 |
|---|---|
| M1切菜 | 菜谱指定每拍落刀或转向；当前番茄谱2刀＋1次右转，全中块、细碎2/8；转向不加细碎度。错键/空拍转向不改切面，漏转向后的切面错误会明确Miss。只有落刀命中才播放切下动作。 |
| M2点火 | 游标到绿色中心时按空格；中心Perfect、边缘Good、区外Miss。 |
| M3下油/下料/翻炒/勾芡 | 左锅WASD，右锅方向键，一拍一键，末拍空格。顺序和时机都参与判断，错一项Good、两项起Miss。 |
| M4炒制控温 | 鼠标靠近温度条弱吸引，按住更强，松手解除；与M3并行，在本锅M6之前结束。双锅任一锅进入调味，另一锅暂时保持当前游标并排除这段稳定率判分，不自动获得Perfect。 |
| M5炖煮 | 相同输入，扰动更慢、范围更宽。E离开后继续，可再去切菜；状态条跨界面常驻。 |
| M6顺序调味 | 在2×5柜中按谱点击盐→糖→油，目标间隔1秒、显示下次点击倒计时；无需同时控温。错料真实加入且Miss；不点不加入。 |
| M7出锅 | 预告→起手等待→长按4拍约2秒→中心松开；等待和蓄力时限独立。中心Perfect、区内Good、区外Miss；始终有界超时，没有自由拖盘。 |

所有输入以同一120BPM四拍时钟为准，强拍金色，底部共享节拍条。50/100ms及所有数值为文档建议/PROPOSED，物理设备延迟未验。右上显示已提交的菜品属性；控温过程条持续显示实时游标，不通过重复读取快照改变菜品。

主要工序2秒预告，键盘/柜子音符通常间隔1秒。绿色Perfect、黄色Good、红色Miss同时显示文字和音符颜色，附早/晚毫秒、错键、漏拍等说明及短音；反馈约0.9秒，最后一步仍可见。空拍可等待，按住键不等于反复命中。

## 蒸菜、炖煮和双锅

- 番茄蒸蛋（TEST_ONLY）：先在砧板备好番茄并搬入蒸笼，再放鸡蛋。空手E后自动M6→上笼长按8拍→留白→M7。M1在之前的实际砧板步骤完成。蒸笼与右锅是同一槽位，不能占用两次。
- 炖牛肉（TEST_ONLY）：右上炖煮食材箱E拿料，放左/右锅，空手E开始点火→M5→出锅。中途E回厨房，观察左下实时条；转去砧板时观察底部常驻条。回来时继续当前进度，不重开控制器。
- 双锅：先分别准备两锅番茄与鸡蛋，左锅E开始后再E返回，右锅E开始，画面自动并列。左WASD/右方向键，共享Space只发给等待Space的操作；没有合法接收方时提前Space会记错。平时一个鼠标吸引两条游标；任一锅调味期间显示火候“托管/暂停判分”，恢复后重新把鼠标移向温度条。
- Esc/失焦冻结游戏、操作与节拍音轨，并释放输入。恢复需要重新按住。E返回厨房不会暂停。返回主菜单再进入会创建干净厨房；已完成菜送出后，放入新材料会创建下一份。
