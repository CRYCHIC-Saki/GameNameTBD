## 怎样试玩

1. 启动 build/TownDiner.exe。新档自动进入新主线；游戏中按 J 继续下一段。
2. 旧档按 J，可选择“切换修订稿主线”：保留钱物、菜谱、房产和经营，只重新开始修订主线。切换和接续接口前须打烊、接待完正在进行的客人。
3. 战斗显示“战斗待制作”，点击下方按钮继续后续剧情、不结算战斗奖励。新增准备接口也明确标为待制作；默认不自动推进。可以停在此处，或主动选择“跳过待制作接口”接续原稿，记录为 deferred，绝不生成战斗成绩、战斗奖励或真实胜利记录。
4. 罗金娜的初次评鉴复用原厨房：完成含鸡肉且未失败的装盘实物，再到 J 提交。随后播放原稿的示范、差距及落败对白；没有额外造出一套战斗算法。
5. J 中的八场完整预览不改剧情进度、库存、关系或解锁。预览包含胜利后台词，便于作者核对，不代表已经完成战斗。

臻味港解禁前，主店只能私下试做；外地分店仍使用原有经营模式。原来的小屋与保存边界保留，新剧情不会把未制作战斗当成经营收入。原稿没有写死的经营天数、收入、评级门槛不擅自补数值；这些新目标仍为待接入接口。当前“百味归港”只作为剧情主题与准备接口，不伪造完整新菜谱。原稿赠送/解锁台词保留，具体战斗掉落与新菜谱奖励暂不结算。
