# 玩家旅程 / Onboarding 剧本（具体案例）

> 目的：用一个**具体玩家**把"做菜 → 开店 → 创造世界菜谱"的完整流程走一遍，
> 既是新手引导（Tutorial）的剧本骨架，也是各系统**首次出现顺序**的验证。

## L1 · 微观：单个工序（秒级）

| #    | 流程   | 玩家经历                      | 岔路 / 结局                          |
| ---- | ---- | ------------------------- | -------------------------------- |
| L1-1 | 切菜节奏 | 8 拍 BGM 按空格，旋转食材决定片/块/条/丁 | Miss → **切到手指**（扣时间，偶尔 −1 SAN）   |
| L1-2 | 控温维持 | 长按微调，抵抗火候扰动               | 过热 → **烧焦**（苦+++）；欠火 → 生         |
| L1-3 | 意外反应 | 屏幕没提示，但口味在悄悄变             | **美拉德/焦糖化**（好）或 **脂肪氧化**（地沟油味，坏） |
| L1-4 | 调味顺序 | 顺序型 QTE                   | 错 → 主导味跑偏                        |
| L1-5 | 出锅时机 | 窗口型 QTE                   | 早/晚 → 香味缺失或过火                    |
| L1-6 | 蓄力   | 热锅/点火长按到区间松手              | 过冲 → 锅太热                         |

## L2 · 单菜交付（分钟级）

| #    | 流程    | 岔路 / 结局             |
| ---- | ----- | ------------------- |
| L2-1 | 标准交付  | 六维结算 vs 客人期待 → ⭐1–5 |
| L2-2 | 加要求   | 客人："再辣点" → **二次加工** |
| L2-3 | 客诉/退货 | 差评（人气−）或退款（金钱−）     |
| L2-4 | 食材耗尽  | 同大类替换凑合，或放弃（客人流失）   |
| L2-5 | 变质食材  | 硬上→差评；丢弃→损失成本       |
| L2-6 | 摆盘    | 只要不"倒出去"都行；倒了→判失败   |

## L4 · 经营决策（周期级）

| L4-6 | 厨师 PK | 赢→解食谱+声望                          |
| L4-7 | 供应链事件 | 涨价/断货/竞价 → 囤货 or 改配方              |
| L4-8 | 网红探店  | 全程直播：爆红 or 大规模差评                  |

## X · 意外 / 故障（穿插所有层级）

打翻菜、双菜冲键、**差评恶性循环**（连续差评→人气下滑→倒闭/降级）、库存腐败。

## B.2 关键节点详述

### 第 1 天 · 教学：番茄炒蛋

- **订单**（外婆）：*“给我来一份甜口的、热乎乎的西红柿炒鸡蛋。”*
- **工序**：切西红柿（要“大块”→ 切 2 次）→ 打蛋炒蛋（**节奏型** QTE）→ 控温（**维持型**，目标 60–65℃）→ 出锅（**窗口型**，命中“西红柿清香”时机）。
- **结算**：口味 前味:酸甜 / 主味:甜 / 余味:甜；温度 61℃；完成度 Q=82；搭配度 H=70；满意度 88 → ⭐⭐⭐；小费 +8。

### 第 3 天 · 第一次翻车：细碎度陷阱

- 阿澈把西红柿切成**丁**（切 3 次）→ 细碎度过高 → 前味大幅增强 → 客人：“太酸了。”
- 结算：满意度 54 → ⭐⭐，小费 0。
- 提示：*“细碎度不是越高越好，要匹配客人要求。”*

### 第 5 天 · 定价

- 首次给菜定价（§8.3）：番茄炒蛋定 12 元（参考价 P₀=11）。

### 第 7 天 · 控温的顿悟

- 常客**老周**（低消费、爱本地咸鲜、要求“咸一点”）。
- 阿澈发现“咸味在 40–65℃ 最突出”，把温度压到 62℃ → 满意度 91 → ⭐⭐⭐⭐，成为回头客。

### 第 10 天 · 第一个特殊事件

- 🔔 **美食评论家 K 先生**光临：*“我想吃一道能代表这个小镇的菜。”*
- 菜单没有 → 查**报刊亭**情报得知 K 先生是广州人 → 用**广东醋+广东酱油**做**广式肠粉**。
- 触发地域加成：完成度 76 / 搭配度 94 / 满意度 93 → ⭐⭐⭐⭐ → 名气 +30，解锁食谱「广式肠粉」。

### 第 25 天 · 厨师 PK

- 邻镇厨师**阿彪**踢馆，比做红烧肉 → 靠控温取胜 → 解锁食谱 + 结识阿彪（可招募为主厨）。

### 第 30 天 · 月度结算

- 💰 3200　🏅 声望 Lv.2　📈 人气 45　🔓 解锁分店前置。

### 第 31–90 天 · 雇人

- 雇「打杂的」小美（300/月）、「备菜的」老王（600/月）。
- **恶性事件**：老王熟练度低，用久置食材 → 触发**氧化** → 差评，人气 −6。
- 学到：**核心菜自己做，杂活才托管。**

### 第 91–180 天 · 分店

- 攒 15000 + 声望 Lv.4 → 解锁**港口镇**（海鲜/生食文化）。
- 流程：设计装修 → 带 3 道自建食谱 → 雇当地厨师阿香 + 店长（1800/月）。
- 教训：当地人**不吃早茶**，广式肠粉滞销 → 改为主打本地海鲜 + 把肠粉做成“异国风情高价菜”。首月 +4200。

### 第 181–300 天 · 低 SAN 主线

- ✉️ 收到**雾港**邀请：进入条件 = 掌握 **5 道低 SAN 食谱**（当前 0）。
- 阿澈主动降 SAN（熬夜、闹鬼码头采集）。
- **第 214 天**：低 SAN（22）下打出 Perfect → 屏幕像素扭曲、BGM 变调 → 产出 **草莓麻婆豆腐饺子**，解锁低 SAN 食谱。
- **第 231 天**：凑够 5 道 → 进入雾港（全城 T3–T4 菜）。
- 首单：居民点**洪鱼脍** → 交付后挂 debuff **「氨味缠身」3 天**（SAN −2/天，社交场合顾客 −10）。

### 第 301 天+ · 终章：创造世界菜谱

- 🎯 目标：把某道菜的**全世界影响力**刷到 100（§8.7）。
- 步骤：汉堡薯条/冰淇淋作基底 → 加融合食材（每加一项完成度 −3）→ 反复试 10 次找平衡 → 同步到全部分店。
- **第 318 天**：命名《六分街的黄昏》→ 5 店同步 → 影响力破 100 → 成就 **「世界的味道」**。

## B.3 引导设计原则

1. **每阶段只引入一个新维度**：手感 → 策略 → 管理 → 扩张 → 猎奇 → 创造。
2. **用失败教学**（第 3 天翻车）比文字教程更有效。
3. **每个新系统都绑定一个具体 NPC/事件**（老周教控温、K 先生教地域、阿彪教 PK、老王教托管）。
4. **情绪曲线**：治愈 → 有策略 → 有压力 → 有野心 → 有猎奇 → 有成就。
