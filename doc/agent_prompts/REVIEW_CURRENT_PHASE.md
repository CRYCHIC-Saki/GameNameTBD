# 审查当前阶段

对当前 Phase 做一次独立验收审查，不增加功能。
先读取总控协议、阶段AC、相关原始设计、用户决策、当前diff和真实测试日志。能使用独立审查Agent时使用；不能时明确是自审，不冒称独立审查。
逐项检查“原需求→已确认规格→实际代码→测试证据”的一致性，重点找假实现、未接入主流程、共用可变Resource、重复结算/奖励、未声明要求扣分、帧率相关QTE和存档污染。
对发现的问题给出严重性、文件位置、复现方法、违反的AC和最小修复建议；先修复关键问题并补回归，再更新阶段记录。
不能将NOT_RUN改成PASS，不能通过删测试、降低原验收要求或把未实现功能改写为延期来通过审查。范围改变必须有明确决定。
