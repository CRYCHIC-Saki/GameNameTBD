开销：租金，基础维护成本（模拟水电费），硬件维护成本（装修和设备等），雇佣工资

供货有延迟，今天订货明天到，除了有特殊buff如“稳定的货源流水线”，“就近的菜市场”等，这些是事件触发或者花钱维护的。

统一度最高100%，
同文化风格装修会显著增加统一度，
异文化风格会稍微降低统一度，
存在“通配风格”（如简约风格，现代风格，生活风格）无论如何都会增加统一度。
高端装修会稍微增加统一度。

公式：
参考价 = 食材成本×制作成本系数+基础价值偏移量

总体装修高端度 = 全部装修高端度的平均值
装修效果 = 装修统一度 * 总体装修高端度


口碑 = 100 * 总好评数 - 5000 * 总差评数
前装修评价 = (装修效果 - NPC对装修水平的期待) × NPC对装修风格的偏好
前品牌评价 = 口碑 × (1 + 0.01×品牌相关的好评数) × NPC对口碑的偏好
前菜品评价 = (NPC预算 - 定价) ÷ (NPC预算 - 参考价) × 100 ÷ (定价 ÷ 参考价 ) × NPC对菜品类型的偏好

竞争优势 =  前菜品评价 + 前装修评价 + 前品牌评价

菜品评价 = 前菜品评价 * (本次菜的质量 ÷ NPC对菜的质量的期待)
总体评价 = （前装修评价 + 前品牌评价 + 菜品评价）÷3
品牌评价 = （总体评价 + 前品牌评价）÷2
装修评价 = （总体评价 + 前装修评价）÷2

评价从0到100，反馈给玩家就是0到40是1星，40到60是2星，60到80是3星，80到90是4星，90到100是5星
NPC对XXX的偏好均属于0到1
