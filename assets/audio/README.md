# 原创占位音乐（D039 / AI-047）

三首循环由本项目`tools/generate_music.ps1`离线合成：casual（80 BPM）、service（104 BPM）、cooking（120 BPM），各32拍，PCM16单声道22050Hz。旋律、和弦、合成音色均为本次原创，没有第三方采样或外部音乐素材。

Godot使用已入库的.wav.import配置；运行时TDGameMusic创建独立循环流，不修改共享模板。烹饪流从厨房初始化开始维持同步相位，隐藏时静音，暂停时冻结；判定反馈不是持续背景节拍器。

这些是可替换的简单占位BGM。实际混音采集通过不代表真实耳机/音箱的听感或键鼠延迟已验收。
